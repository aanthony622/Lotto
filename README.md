# Lotto Number Generator

A simple static web app that generates:

- 5 random numbers between 1 and 70
- 1 random number between 1 and 20

## Run locally

Open `index.html` in your browser, or serve the folder from a local web server.

> Note: This branch includes a dev-only update to demonstrate a pull request workflow.

## Files

- `index.html` — app UI
- `styles.css` — page styling
- `script.js` — random number generation logic
